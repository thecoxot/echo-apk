# TCP fallback — cellular carriers and many VPNs/firewalls silently drop UDP, so QUIC never
# completes ("реле active 0/N — сеть блокирует QUIC/UDP"). TCP almost always passes; the relay
# listens on TCP at the SAME port 4001. Clients try all addresses and keep whichever connects.
/ip4/217.199.252.199/tcp/4001/p2p/12D3KooWK2M6pWojUjJVAyRg6e54dzKM93qkZYLPyzWh7WFMDYfo default
# IPv6 TCP fallback — a v6-only phone (modern cellular) on a UDP-blocking network had NO path before:
# v4 is unreachable, and the v6 entry above is QUIC-only. The relay listens dual-stack on TCP
# [::]:4001, so this one line covers v6-only AND UDP-blocked at the same time.
/ip6/2a03:6f00:a::2:1f5d/tcp/4001/p2p/12D3KooWK2M6pWojUjJVAyRg6e54dzKM93qkZYLPyzWh7WFMDYfo default

# port 443 (which passes almost everywhere) reaches the same node. coxot.ru keeps :443 on the MAIN
# IP — untouched. (Port-block bypass; deep-DPI networks may still see it isn't real TLS.)
